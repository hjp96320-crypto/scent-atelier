## 已实现的设计体验

- 四个主入口：今日灵感、香水图鉴、调香室、我的香气；调香采用选香、调比例、注入与保存三步页面，商品详情和命名封瓶使用浮层。
- 几何玻璃瓶、基底瓶倾倒、连续细流与液面变化、作品标签。三种瓶型，金银喷头与金银/无外盖独立配置，无试喷。
- 90 款香气统一选香，不分商家入口；用 8 个通俗类别、中英文搜索及生活化气味说明查找，正式中文名作为卡片小字保留。新用户从空选开始，选 3–4 种后再调比例；自由选香首次或改选后均分，相同集合返回保留手动比例。24 个编辑灵感起点统一可选，原始材料 ID 与来源元数据保留。
- 比例页支持滑块、数值输入与平均分配；一位小数百分比、合计 100% 校验，10 / 30 / 50 / 100 mL 名义投料总量。配比有效后才开始注入；调整当前配方且用量未变时继续原进度，灵感试配及作品复用明确开始新瓶；保留最近一份原草稿供切回。
- 长按注入、松开暂停、指针移出/按钮失焦/切页/后台停止、单款到量自动停、一次加入、会话内撤销。
- 已应用配方与注入进度刷新恢复；封瓶作品、实体香柜、气味日记存于 localStorage；JSON 导出备份。
- 每款到量后可直接选择“下一款”；全部完成显示独立“保存作品”入口。保存成功后才标记封瓶，失败保留可重试草稿；支持查看作品、再调一瓶与复用配方。
- 26,335 条图文档案、1,263 个品牌标签；支持品牌、国家／地区、香型组合筛选和中英文多关键词搜索。品牌按原名 A–Z 分组并可搜索，国家／地区按洲分组。名称与香调中文优先，全部条目提供三阶段气味说明；来源保留在数据与研究文档中。
- 品牌筛选默认展示 12 个热门品牌快捷项，优先香奈儿、迪奥、爱马仕、祖玛珑，保留完整字母分类与搜索。
- 按最新反馈取消独立浓度筛选和未知提示，明确 EDT／EDP 等版本继续保留独立档案与香调；内部版本核对资料保留。
- 全部 26,335 款具备前中后三阶段说明；3,807 款完整来源分层及 1 款部分分层保留，未公布层级结合整体香调给出明确标注的试香解读，不再显示缺项占位文字。来源资料覆盖与说明覆盖分开统计。详见 `../docs/16-全量香气说明与用香日历.md`。
- 今日页加入月历、日期选择、记录数量和月度统计；点日期查看用香或补记，保存后更新日历，沿用本地日记存储。手选天气和活动，基于实体香柜提供描述性提示；没有虚构实时天气或个人拥有状态。

## 历史验证记录（三步流程改版前）

本机浏览器实际操作通过：

1. 长按部分注入后暂停，撤销回到开始量；继续长按到 4.0 mL 后停止，其他材料保持不变。
2. 一次加入第二款至 3.5 mL，最后一款长按至 2.5 mL；总量恰为 10.0 mL，完成后另行点击命名。
3. 命名、封瓶、作品收藏、开始下一瓶、刷新恢复。
4. 加入第四款后 110% 配比被拦截；调整到 100% 后可以应用。33.3 / 33.3 / 33.4 显示为 3.33 / 3.33 / 3.34 mL。
5. 手机商品详情、标记拥有、今日选香、保存日记、刷新后读回、移出香柜。
6. 导出 JSON 实际下载并解析成功，含 1 条明确标注的体验作品和 1 条交互验证日记；实体香柜已恢复为空。这些测试内容不是用户真实使用记录。
7. 调香室在 375、768、1024、1440px 宽度及 812×375 横屏下没有横向溢出。375px 图鉴、详情和四基底配方已目视检查。1440px 调香室和真实图鉴已保存截图。
8. 浏览器控制台没有捕获到 error / warn。Node 语法检查和 `node blend-model.test.mjs` 通过；覆盖精确总量、超量截断、无效配比、超精度、草稿恢复与封瓶状态约束。

关键颜色对比度计算：主文字/纸色 12.47:1，次级文字/纸色 4.88:1，主按钮文字/苔绿 7.32:1。正文与按钮色已检查；不将其表述为整站 WCAG 认证。

本轮代码审查后补上了保存失败回滚、按钮失焦停止、一步加入前停止长按、两位用量显示。存储配额耗尽、多指并发、不同系统读屏器与系统减少动态效果开关没有做设备级实测；对应分支已实现并审阅。长按键盘替代、焦点圈与原生 dialog 已提供，不宣称完整辅助技术兼容认证。

## 当前边界

- 成品香水的虚拟混配，mL 是加入前体积之和，不保证实际混合后体积严格相加，不从 EDP 猜浓度，不默认加酒精。跨来源选香是虚拟玩法，不代表实物混配的安全性、相容性或气味效果已验证。
- 液色为视觉示意；气味短句为编辑联想，非化学或嗅觉模型预测。虚拟封瓶不代表已实体制备。
- 90 款基底与26,335条图文档案用于本地原型；不代表完整市场数据库。基底目录范围见 `../docs/14-热门品牌与90款基底及保存流程.md`；图鉴图片与资料核验范围见 assets/README.md 及 `../docs/11-缺图补齐与地区信息核对.md`。
- 90 款材料的来源为 Galimard 18 款与 Demeter 72 款，前台统一呈现；商家业务接口、浓缩模式、云同步、实时天气/外部日程同步、化学量化模型均未实现。
- 选香和配比编辑自动保存草稿；注入撤销历史仅在本次页面会话中有效。日记可编辑；日记和作品可移入最近删除并恢复。备份支持有效记录合并导入、逐项冲突选择和导入前快照；导入保留本机草稿，不替换正在进行的调配。作品重命名、备注和草稿从外部备份恢复仍待后续完善。
- 仅有浅色主题。没有公网部署，没有执行真实调香操作。
