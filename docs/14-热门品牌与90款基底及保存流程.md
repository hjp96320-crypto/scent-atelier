# 热门品牌、90 款基底与保存流程

更新：2026-11-08。

## 选香规模与来源

本轮扩充的是可选基础香气，而不只是增加少量材料的预设排列。按用户最新要求，90 款香气合并为一个选香目录，不再让用户先选商家；先选 3–4 种喜欢的气味，再调整比例，最后注入与保存。允许在虚拟玩法中跨来源选择，原始材料 ID、正式名称和来源元数据继续保留。

下表仅说明数据来源，不是前台分类或选香限制。

| 系列 | 本应用收录 | 材料形态 | 核对来源 |
| --- | --- | --- | --- |
| Galimard | 18 款 | 套件的已稀释、可直接使用的基础香水 | [官方套件完整名单](https://www.galimard.com/produit/coffret-leleve-parfumeur) |
| Demeter | 72 个独立香味 | Cologne Spray 成品古龙水，不是 Perfume Oil | [官方喷雾目录](https://demeterfragrance.com/collections/cologne-spray)、逐款商品页 |

原有 6 款 Galimard ID、中文名和显示字段保持兼容，已保存作品与草稿可继续恢复。Demeter 的 72 款使用独立 ID；不同容量没有重复计数。逐款原名、喷雾版本和官网 URL 保存在 `research/diy-bases/demeter-72-sources.json`。

[Demeter 官方混配说明](https://demeterfragrance.com/pages/foolproof-blending-stories)提供成品香水的混配分类与瓶内混配方式。Galimard 的[官方指南](https://www.galimard.com/wp-content/uploads/2020/09/Conseils-dutilisation-User-guide.pdf)另有自身选材数量与阶段要求；本应用统一的 3–4 款玩法和预设比例是编辑试配，不能称为 Galimard 官方流程。

中文名称、香型导航标签、气味联想及液色均为编辑整理；液色不是产品实物颜色，体积比例不是气味强度。当前均按成品香水作虚拟计量，不猜精油浓度、不默认额外添加酒精。跨来源自由选择仅表示应用允许虚拟搭配，不代表已经验证不同商家实物混合后的安全性、相容性或气味效果。

## 交互调整

- 调香采用“选香 → 调比例 → 注入与保存”三个明确步骤，新用户从空选开始；已有草稿可继续原来的调配。
- 90 款香气统一按 8 个通俗类别浏览：柑橘果香、花朵香气、茶与绿叶、树木与森林、海风与雨水、干净柔软、甜点与咖啡、辛香与暖香。支持生活化名称、正式名称、英文名与气味描述搜索。
- 香气卡片以熟悉的生活名称和具体气味联想为主；与展示名不同时，正式中文名作为“原名”小字保留，不更改材料身份或已保存配方。
- 点击卡片选入，再点一次取消；已选托盘支持移除和清空，最多 4 种，少于 3 种不能进入调比例。选香阶段不要求先理解百分比。
- 自由选香首次进入比例页或改变已选集合后，重新平均分配：3 种为 33.3%／33.3%／33.4%，4 种各 25%。返回选香但集合不变时保留手动比例，改变排列顺序也不重置。
- 比例页支持滑块、数值输入、平均分配和 10／30／50／100mL 总量；每项至少 0.1%、保留一位小数且合计为 100% 才能开始注入。数量与比例的校验由计量模型再次执行。
- 24 个灵感起点统一展示，按清新柑橘、茶感绿意、柔和花香、温暖木质、甜香美食查找。方案提供比例、搭配理由、场景和调整方向；工作台从全部 24 个方案中按共有香气数量排序，展示最相关的 3 个，不再按来源隐藏方案。
- 选择灵感方案后先进入选香与比例流程，不自动注入。开始新试配时保留最近一份原草稿，可切回；在调整当前配方时，如果容量、香气集合与比例都未改变，则继续当前注入进度。灵感试配和作品复用明确开始新瓶，即使比例恰好相同，也从 0 mL 开始。
- 单款到量后出现“下一款”引导，明确显示已完成几款。全部到量后出现独立“保存作品”按钮和“待保存”状态，不再复用长按注入按钮作为命名入口。
- 保存成功后显示“查看作品”和“再调一瓶”；作品详情显示香气、比例和包装，复用配方返回选香流程，正式开始新试配前保留原草稿。
- 品牌筛选默认展示 12 个热门快捷项，前四项为香奈儿、迪奥、爱马仕、祖玛珑。其余为娇兰、圣罗兰、汤姆福特、古驰、乔治·阿玛尼、普拉达、博柏利、蒂普提克。这是编辑快捷选择顺序，不是销量排名；原 A–Z、数字分组和搜索保留。

## 保存修复的证据边界

旧版保存流程在当前浏览器可完成，未直接复现用户现场的失败。代码与条件测试确认一个缺陷：旧处理器先把草稿设为已封瓶，再生成 UUID；UUID API 缺失时会留下“已封瓶但没有作品”的半提交状态。

新增 `saveFinishedBlend()` 在独立候选对象中准备作品，持久化成功后才更新当前草稿与作品列表。UUID API 缺失时生成本地作品 ID。存储失败保留原状态并显示可重试错误；新建、编辑及复用配方也检查写入结果，避免页面与刷新后状态不一致。

## 已取代的交互规则

2026-11-08：用户明确要求统一来源后，旧版“先选商家、同商家混配、推荐只展示当前系列”的限制被统一 90 款目录取代。旧版移除材料时保留剩余比例的单页编辑方式，也被“先选香，再调比例；改变集合重新均分”的三步流程取代。
