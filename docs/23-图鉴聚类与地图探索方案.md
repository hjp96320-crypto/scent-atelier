# 图鉴聚类与地图探索方案

日期：2026-11-08。本文保留实施前方案与当时盘点；数据分析、一期和二期的当前结果分别见文档 24、25、26。下文“尚未／未完成”描述的是方案提出时的状态，不是当前实现状态。

本轮完成现有数据盘点、可视化方法与工具调研。尚未运行聚类、生成实际坐标或改动图鉴页面；以下分组名称和交互均为设计提案。

## 1. 推荐方案

在现有图鉴内提供「卡片 / 香气星图 / 品牌地图」三个视图，共用搜索、品牌、香型、国家地区筛选。保留卡片作为默认入口，让用户按需要切换探索方式。地区与香型的交叉分析作为地图中的展开面板，避免主页同时塞入多张图。

| 视图 | 用户想解决的问题 | 主要呈现 | 核心操作 |
| --- | --- | --- | --- |
| 卡片 | 找到具体香水、确认版本与资料 | 现有真实瓶图和中文档案 | 搜索、筛选、打开详情 |
| 香气星图 | 我喜欢这一瓶，还可以了解什么？ | 按已列香调相似度排列的二维点图 | 搜索定位、缩放、点选、查看邻近香水 |
| 品牌地图 | 某个地区有哪些品牌和香水？ | 国家/地区分级设色地图与同步列表 | 洲导航、点选地区、查看品牌、转到星图 |
| 地区 × 香型面板 | 不同地区的收录档案在香型上有何差异？ | 热力图，可按香型分布相似程度排序 | 切换数量/覆盖率、点击单元格筛选 |

**产品主线：从一瓶熟悉的香水出发，找到共同的气味线索，再探索新的品牌。** 地图是另一条探索入口，不让用户先理解统计术语才能使用。

## 2. 当前数据能支持什么

本地审计直接读取运行中的数据构建模块，结果见 [data-audit.json](../research/catalog-visualization/data-audit.json)，脚本见 [audit.mjs](../research/catalog-visualization/audit.mjs)。

| 项目 | 本次盘点 | 对方案的影响 |
| --- | --- | --- |
| 图鉴规模 | 26,335 条档案、1,263 个品牌 | 使用全量档案建图，浏览器分层显示 |
| 地理维度 | 48 个国家/地区标签 | 可做国家/地区探索；没有城市坐标 |
| 香型 | 15 类；一款可属于多类 | 适合筛选、着色及交叉分析，不能把多标签占比相加当成 100% |
| 香调 | 原始词表 536 项；每款中位数 8 项 | 可以建立香调特征和相似关系 |
| 中文展示香调 | 1,564 种字符串 | 与原始词表不等价，需先统一同义词及中英文映射 |
| 精细资料 | 100 个具体版本经过近期专项完善 | 可作为人工检查聚类结果的重点样本，不代表全库逐款核验 |
| 分阶段香调 | 3,810 条由现有程序标为 documented，其余使用气味演变解读 | 第一版不把解释性前中后调作为聚类事实输入；documented 也不等于全部来自官网 |
| 浓度 | 24,966 条为 unknown | 不用于连续坐标或推测强度；已明确版本保留独立 ID |
| 图片 | 每条都有图片引用 | 点选后复用真实瓶图；本次未重新验证全部文件加载与图片版本匹配 |
| 其他数值 | 当前模型没有价格、评分、销量或上市年份字段 | 不生成热销榜、市场占有率、年代分布等图表 |

需要先处理的两项数据问题：

1. EVODY、MONCLER 各存在法国/意大利两种地区标签。需查清源字段是品牌起源、总部还是其他归属，确定统一口径再改；尚未确定的条目进入“地区待确认”，仍计入总数。其他品牌亦需做来源口径和抽样核查，不能仅凭标签非空声称已全部确认品牌起源。
2. 2,650 条档案与其他档案拥有完全相同的原始香调集合，涉及 1,036 组。相同标签不代表同配方，也不应合并具体版本；图上重叠时展示“这里有 N 款”，通过列表选择。

统计单位始终是“已收录档案条目”。原始数据库包含历史资料，地区数量不能外推成当地市场规模、消费者偏好或全球品牌完整名录。

## 3. 香气星图：有依据的坐标，而非装饰性散点

### 数据如何变成坐标

1. **统一香调词典。** 以稳定的香调 ID 连接原始词、中文名、同义词。保留“玫瑰”与“保加利亚玫瑰”等层级关系，避免简单粗暴地全部合并。已精细核验的版本优先使用其明确列出的香调；其他档案使用原始香调。两套描述不重复叠加。输出未映射词清单与逐款映射覆盖率。
2. **建立特征。** 第一版只使用明确列出的香调，比较二值标签与 TF-IDF 权重两种方案，用余弦相似度或 Jaccard 相似度检查邻居是否合理。品牌、国家、营销文案和程序生成的场景/前中后调解说不进入特征，避免模型重复我们自己的编辑规则。
3. **生成二维布局。** 推荐试验 UMAP，把高维香调关系投影到二维。坐标无物理单位，不把横轴写成“清新—浓烈”、纵轴写成“甜度—木质度”。用户只需理解“附近的点，通常拥有更多相似香调线索”。较远点之间的距离不作精确比较。
4. **识别群组。** 试验在适度降维的特征空间中使用 HDBSCAN，并回到原始香调空间检查分组，不直接按屏幕上二维点的位置划定真实类别。允许一部分档案没有稳定归属；不强制每款塞入某个群组，也不预设刚好 15 群。
5. **生成可读说明。** 根据群内有代表性、相对其他群更突出的香调命名，例如“柑橘与芳香草本”。这些是待计算后审查的名称示例。点选后的相近推荐由原始特征相似度排序，而非直接按屏幕距离排序。

UMAP 官方说明提醒，二维投影可能扭曲密度、产生看似分离的区域。因此“看起来像一团”不能单独证明存在稳定香气类别。[UMAP 聚类说明](https://umap-learn.readthedocs.io/en/latest/clustering.html)

HDBSCAN 适合尝试密度不同的群组，并可保留未归类项；是否适合本库要由实际结果决定。如果分组不稳定，首版仍可交付相似度布局，用现有香型作导航，不包装未经验证的自动群组。[HDBSCAN 文档](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.HDBSCAN.html)

### 怎样让它好用

- **缩小时看概览，放大后看单款。** 总览使用聚合点与少量标签，逐级显示档案点；不同时绘制 26,335 张瓶图。
- **从熟悉的一瓶开始。** 搜索名称后定位、高亮该点，打开瓶图、具体版本、共同香调和差异香调。保留“查看完整档案”“加入香柜”。
- **筛选不打乱位置。** 布局预先计算并固定；筛选只隐藏或弱化不匹配项，保留地理式的空间记忆。提供“适合当前结果”缩放按钮。
- **同香调、不同版本仍能选择。** 重叠点打开条目列表，明确 EDT、EDP、Parfum 等已知版本；未知浓度保持未知。
- **颜色一次表达一个维度。** 默认使用少量可区分的香型色组，完整香型仍在筛选和详情中展示；可切换按地区着色。多香型档案的点色仅是展示归组，不替代其完整标签。选中、筛选和香柜状态同时使用描边或图标，避免只靠颜色区分。
- **不伪造量化感。** 不展示“气味相似 93%”“比它浓烈 20%”或分子浓度。页面轻提示“按已列香调排列，供选香参考”；详细方法放说明面板。

如果以后需要带有直观横纵轴的坐标图，可以另做“柑橘相关香调占比 × 木质相关香调占比”等可计算视图。但它表示资料中的标签比例，不是鼻子感知到的强度，暂不纳入第一期。

## 4. 品牌地图与地区聚类

### 地图的口径

地图名称建议为“品牌地图”，副说明写“按档案中的品牌国家/地区探索”。有来源支撑且口径统一后，才改称“品牌起源地”。不把同一个字段同时解释成原产地、总部、生产地和香料产地。

默认颜色表示当前筛选结果中各地区的**去重品牌数**，可以切换为“档案数”。使用标注清楚的分档色阶，悬浮或点选显示实际数量；零条收录与地区未匹配分别显示。地图旁始终提供可排序列表，避免小国家/地区难以点击。洲导航复用现有分组，跨洲分组只影响导航，不重复计算档案。

国家/地区边界使用本地静态数据，不虚构品牌经纬度，不添加无意义的城市标记。中国香港等现有独立地区标签与小面积地区通过区域视图/列表保留可选性；实施时核对中文名称、几何边界及归属映射。可选底图来源 Natural Earth 的数据为公共领域，但仍需检查它与本应用地区口径是否一致。[Natural Earth 使用条款](https://www.naturalearthdata.com/about/terms-of-use/)

示例路径：点选“法国” → 显示该地区的品牌与档案 → 选择一个香型 → 切到星图，保留相同筛选条件。

### 地区 × 香型热力图

每行一个地区，每列一个香型。默认单元格为：

`当前筛选结果中，该地区含此香型的档案数 ÷ 该地区档案总数`

名称使用“香型覆盖率”。同一档案可能计入多个香型，因此行内百分比合计可以超过 100%；点选单元格同时显示分子、分母与对应档案。提供“档案数量 / 地区内覆盖率”切换，避免大样本地区天然占据所有深色。

第二期可按这些香型覆盖率向量的相似程度，对地区进行层次聚类排序。它回答“哪些地区在本库中收录的香型结构相近”，不声称代表各国消费者的口味。小样本地区保留展示并标记样本量；初版建议少于 20 条不参与地区聚类，阈值需在分析报告中展示敏感性检查。

## 5. 页面结构与视觉方向

延续当前浅色、深绿色主色与 iOS 风格控件。图表区域用实体浅底、细线和清晰标签；玻璃感只用于浮动导航与工具条。星图不做夜空背景、发光粒子或旋转 3D 球。

```text
图鉴                   搜索香水 / 品牌 / 香调
[ 卡片 | 香气星图 | 品牌地图 ]
[ 香型 ] [ 品牌 ] [ 洲 / 地区 ]   已选条件 ×

桌面：
┌──────────────────────────┬─────────────────┐
│                          │  选中香水真实图  │
│    星图 / 地理地图         │  名称、具体版本  │
│    缩放、定位、清除选择    │  共同与不同香调  │
│                          │  相近档案列表    │
└──────────────────────────┴─────────────────┘
图例 · 当前结果数               查看结果列表

手机：搜索与视图切换 → 精简筛选 → 图形 → 点选底部抽屉
```

手机默认点选与双指缩放，不依赖悬浮提示；图形中的小点使用最近点拾取和候选列表，导航按钮至少 44px。保留页面滚动，不让地图吞掉整页手势。底部详情抽屉避开现有导航与安全区，返回图形时保留缩放与选择。

图形有可读的结果列表替代；键盘可操作筛选、选中结果与详情。减少动画偏好下关闭自动飞行动画。没有结果时显示当前条件和清除入口，不能留下无法解释的空白图。

## 6. 参考工具与技术取舍

| 工具 / 方法 | 借鉴内容 | 本项目的采用方式 |
| --- | --- | --- |
| [WizMap](https://github.com/poloclub/wizmap) | 地图式探索高维数据、多层级摘要、搜索定位 | 最主要的交互参考；借鉴渐进展示，不整体搬入其应用 |
| [Nomic Atlas](https://docs.nomic.ai/atlas) | 文本、图片与向量的联动探索 | 参考“点选数据 → 看原始内容”的体验；当前方案在本地处理资料 |
| [kepler.gl](https://docs.kepler.gl/) | 地理分析、图层与筛选 | 参考地图与列表联动；消费者 H5 不暴露完整 GIS 操作台 |
| [Apache ECharts](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/) | 图形渲染与交互 | 第一选择：复用原生 JS 页面，星图用 Canvas；地图、热力图共用一个绘图库 |
| [deck.gl ScatterplotLayer](https://deck.gl/docs/api-reference/layers/scatterplot-layer) | WebGL 散点层 | 仅在实测性能不达标时评估，不在第一期同时引入多套渲染栈 |

ECharts 官方对较多图元建议优先考虑 Canvas，但 26,335 条档案在本应用上的流畅度仍需实测，不能从工具能力直接推定手机性能。首版通过聚合显示、延迟加载图库、点选后加载瓶图减少负担。

推荐数据路径：本地脚本规范化香调 → 计算特征、邻居、聚类与二维坐标 → 生成版本化静态文件 → H5 加载并复用现有详情与筛选。浏览器不现场训练模型；不迁移 React、不接入额外账户或在线地图服务。

构建产物保留稳定档案 ID、坐标、可选群组、映射覆盖率、邻居索引与数据版本。固定随机种子和词典版本，保存每次构建的参数与验证结果；更新数据时明确布局版本，不在每次打开页面时随机重排。

## 7. 分期执行与验收

### 第一期：可用的全量探索

1. **整理数据基础。** 统一香调词典、核查地区冲突和字段语义、建立地图区域映射。验收：原档案 ID 全部保留；未映射项明确列出，不静默丢弃。
2. **试算并评估布局。** 使用全量档案，比较标签二值/加权方案；检查 100 个精细档案及资料稀疏、同香调、不同版本等边界样本。评估邻居重合率、跨随机种子的邻域稳定性和抽样 trustworthiness；指标衡量资料结构保留程度，不代表实闻正确率。[trustworthiness 定义](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.trustworthiness.html)
3. **接入三个视图。** 实现星图、品牌地图、搜索定位、共用筛选、真实图片详情与相近档案列表。验收：相同筛选下各视图的档案集合一致；地图地区计数加未匹配项等于结果总数；点击群组和地区能回到准确档案。
4. **验证交互与性能。** 桌面和手机宽度检查选择、缩放、抽屉、空状态、重叠点及键盘操作；检查现有自动测试与图鉴、香柜、调香、今日流程回归。性能目标先以缓存加载后的视图切换约 1 秒内、筛选约 300ms 内反馈、拖动约 30fps 为试验目标，记录测试设备和数据量，不作为已达成结果。

第一期允许暂不展示不稳定的自动群组；但必须有真实香调驱动的坐标、可解释的邻居结果和地理探索，不能用随机散点代替算法。

### 第二期：比较与个人探索

- 地区 × 香型热力图，以及地区分布相似性排序。
- “只看我的香柜”和“从这瓶出发”，在同一全局坐标中看个人收藏。
- 同系列不同版本对比；把共同香调与差异香调并列呈现，保留资料来源范围差异的解释。

化学分子、真实强度、持香、扩散和个性化喜好预测需要不同的数据基础，不由香调名称自动推导，暂不纳入以上两期。
