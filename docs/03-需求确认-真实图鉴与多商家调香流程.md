# 需求确认：真实香水图鉴与多商家 DIY 流程

日期：2026-11-07  
状态：用户需求已确认；数据候选完成小样本核验，尚未接入应用。本文覆盖早期文档中与其冲突的方案假设。

## 1. 本次确认

- 正式图鉴必须使用真实香水品牌、真实产品图片和可追溯的信息，优先复用现成数据库。
- 不用教学概念产品、生成瓶图或通用图标替代真实商品内容，不能把这些替代物算作图鉴完成量。
- 调香功能遵循真实 DIY 的步骤，展示目标成品量、各 base 用量和必要的稀释步骤，而非只调感官滑杆。
- 交互以选 3–4 款完整 base 为主；商家有不同的选择数量或用量规则时沿用其规则。
- 不绑定日本商家或私人配方卡。此前案例仅帮助理解体验形式；数据结构与流程面向不同商家、套件及供应商。

## 3. 先区分 base 的物料形态

“精油”不是所有香料的统称。产品界面使用准确名称：天然精油、香精/复合香料浓缩液、已稀释基础香水。base 也不等于香调金字塔中的尾调（base note）。

| 模式 | base 实际是什么 | 流程含义 |
|---|---|---|
| 已稀释基础香水混配 | 已含酒精/其他载体的完整香水或专供混配的基础香水 | 按商家允许的组合和配比混合；不默认再增加 80% 酒精，也不从 EDP 名称猜出精确浓度 |
| 浓缩香料调配后稀释 | 供应商明确说明规格、溶剂与用途的浓缩香精/香基 | 确定商家支持的目标负载和计量口径，再分配各 base，计算载体用量 |
| 规格未知 | 只有编号或香气描述，浓度、载体或计量口径不明 | 可保存配比与原始用量，不生成确定的稀释或成品浓度建议 |

官方流程证据：EPC 的 Creation Sets 提供三款可独立使用的 EDP，并指导选择两或三款混合；Galimard 的创作套件提供 18 款已达 EDP 浓度、可直接使用的基础香水及一个 100 mL 成品瓶。因此不能把所有 DIY 套件都视为未稀释精油。[EPC](https://experimentalperfumeclub.com/pages/perfume-creation-sets)、[Galimard](https://www.galimard.com/en/product/perfume-creation-kit)

3–4 款是本应用主要交互规模，不是通用化学上限，也不是所有商家的统一规则。

## 4. 应用中的真实步骤

1. **选择商家/套件目录或供应商方案**：显示 base 身份、已稀释/浓缩状态、计量口径和适用的混配规则。默认在同一套明确可混配的目录内操作。
2. **浏览/实际试闻并选 base**：默认从 3 款开始，可增至 4 款；明确支持 2 款的商家沿用其流程。界面可解释主体与点缀，但不强制凑齐“一款前调、一款中调、一款后调”。
3. **先做小样与调比例**：设定小样量、记录用量和实闻反馈，保存候选版本。未实际试闻时标明仅为模拟描述。
4. **确定成品量与配方口径**：选择例如 30/50/100 mL 的目标容量；按重量工作的方案使用 g。浓缩模式选择有依据的香料负载及其 %w/w 或 %v/v 定义；成品 base 模式不强行新增浓度选项。
5. **换算与制备清单**：根据最终比例生成各 base 的 g 或 mL，按相应方案决定是否需要载体。缺少必要规格时只保留比例，显示缺少哪项输入，不猜量。
6. **复评、命名与留档**：按对应商家/供应商流程执行静置、复闻、必要处理与装瓶，保存材料版本、实际用量和体验。静置时长、过滤等不写成适用于所有 base 的固定步骤。

应用模拟和计算这些步骤；实际嗅觉仍来自线下试香。用量计算正确不等于完成了实体配方的适用性或安全评估。

## 5. 100 mL 到底需要多少香料

没有统一答案，必须先知道 base 是否已稀释、目标浓度的定义及供应商适用方案。

### 5.1 明确假设后的体积示例

仅示范算术：**未额外预稀释的香精浓缩 base、目标最终体积 100 mL、香精添加比例 20% v/v、三款体积投料比例 40:35:25**。这里把 20% 明确定义为“三款 base 加入前的体积之和 ÷ 最终成品体积”；如果改为先预混再量取，须采用一致的预混物计量口径。

| 项目 | 名义计量 |
|---|---:|
| base A | 8 mL |
| base B | 7 mL |
| base C | 5 mL |
| 香精浓缩液合计 | 20 mL |
| 对应方案规定的载体 | 按方案补足最终体积至 100 mL |

20% 是演示设定，不是所有 EDP 或所有原料的统一配方。香精浓缩物本身也可能含配方溶剂，这里计算的是香精投料比例，不自动等于纯芳香物含量。不能笼统写成“20 mL 天然精油”；也不能保证 20 mL 香料与 80 mL 溶剂混合后的最终体积严格为 100 mL。体积配比、定容与温度条件应按方案处理。

### 5.2 重量示例

若采用 **100 g 成品、20% w/w 的上述浓缩液添加比例、40:35:25 的质量配比**，则 A/B/C 为 8/7/5 g，载体总量为 80 g。该算例得到的是 100 g，不等于 100 mL；缺少适用密度信息时不能互换，也不能从香精投料质量直接推断其中纯芳香物质量。

### 5.3 已稀释 base 的处理

已稀释基础香水不能套用上述未稀释浓缩液算例。只有各项浓度口径一致且已知时才能计算。

以质量口径为例：`最终香料质量分数 = Σ(base 质量 × 该 base 已知香料质量分数) / 成品总质量`。浓度未知时结果保持未知；不能把商品标有 EDP 当作已知的 20%。不同载体或不同商家的体系，也不能在缺少混配依据时自动生成实体操作建议。

## 6. 对既有方案的调整

- 撤回“30 款教学概念 base 作为正式首发目录”的方案。正式目录优先真实、可追溯、可支持对应流程的商家或供应商材料；教学内容只可用于明确标记的原型测试。
- “数十款”保留为范围目标，不通过虚构材料凑数。接入数量以实际核验结果报告。
- 将旧的 1–6 款设计收敛为以 3–4 款为主，具体以目录流程支持范围为准。
- 在配比之外增加商家/方案、物料形态、成品量、计量单位、浓度定义、必要规格和制备清单。
- 不再以日本私人配方作为通用流程或产品默认演示。
- 不宣称单一免费库已解决所有资料与真实图片需求；数据接入、图片匹配和许可记录分别验收。

当前可继续推进真实目录的小样本接入验证；完整目录覆盖、图片匹配、商家 base 规格和浏览器端展示仍未完成。
