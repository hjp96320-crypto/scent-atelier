# 拟物调香室：页面与交互设计

日期：2026-11-08  
状态：交互与视觉设计规范；本轮已制作局部可交互 H5 原型，实际实现与验证范围见 `../prototype/README.md`。本规范仍包含后续目标，不表示以下功能全部实现。  
需求依据：[真实图鉴与多商家调香流程](03-需求确认-真实图鉴与多商家调香流程.md)、[PRD v0.1](02-香水图鉴H5-产品需求文档-PRD-v0.1.md)。与早期默认入口不同，本轮以调香台为首页。

## 1. 本轮设计方向与范围

把 H5 做成一间可以停留、试配和收藏作品的私人调香室。视觉采用暖白墙面、浅木桌面、透明玻璃器皿与纸本配方；情绪来自亲手完成一个小作品的过程，以及作品被认真保存的感觉。

**浅木方向是本轮工作默认，不是用户已经从此前三张静态方案中选定的结果。** 用户已明确要求使用 ui-ux-pro-max 设计，并希望拟物操作提供情绪价值；颜色、材质细节和动效节奏仍需在可交互原型中评估。

本轮原型集中验证已稀释 EDP base 的虚拟混配：选 3 款为默认引导，目录支持时可选第 4 款；商家只支持 2–3 款时沿用该范围。使用真实材料身份与可追溯资料，不把完整香水换成单分子旋钮。虚拟注入和封瓶只创建数字作品，不表示用户已实际调出或拥有实体香水。

## 2. 视觉与材质规范

| 元素 | 设计要求 | 功能目的 |
|---|---|---|
| 背景 | 暖象牙 `#F4F0E8`；轻微纸面颗粒，避免整屏强纹理 | 提供稳定、安静的阅读底色 |
| 文字 | 棕墨 `#302A23`；正文不使用低对比浅棕 | 在木色、玻璃和纸面上保持清楚 |
| 主操作 | 苔绿 `#4D5940`，浅色按钮文字；主按钮保持实色底 | 让“开始试配、封瓶收藏”等动作易发现 |
| 点缀 | 金棕 `#9A7446`，用于刻度细节、标签边线或装饰 | 只作少量强调；小字颜色仍需逐项测对比度 |
| 桌面 | 浅木暖色，低对比纹理，桌缘与柔和接触阴影 | 为器皿提供落点，不压过真实商品图 |
| 玻璃 | 透明主体、少量高光、细轮廓与柔和阴影；液面是进度示意 | 让加入量变化可见，不依赖昂贵三维渲染 |
| 配方纸 | 近白实底、1px 分隔线、小幅层叠；正文区域不透明 | 提供可阅读、可核对的配比记录 |
| 标题与正文 | 标题用 Noto Serif SC 或可用中文宋体；正文用中文无衬线系统字体 | 保留纸本气质，同时保证输入与长文易读 |

正文默认 16px，行高约 1.6；数字使用等宽数字，避免用量变化时左右跳动。辅助说明原则上不低于 14px。间距使用 4/8px 的递增体系；图标使用同一套线性 SVG，旁边有可读动作文字，不用 emoji 作为导航。

拟物集中在桌面、器皿、配方纸、标签和封瓶动作。搜索框、表单、导航沿用熟悉的网页控件。玻璃效果不承载低对比正文；真实商品照片保持比例与原有瓶身，不重新绘制成“仿官方”包装。调香台中的通用玻璃容器是虚拟工具，不充当任何真实商品图片。

首版只设计浅色主题；不把尚未设计与验证的深色模式列为完成能力。

## 3. 页面结构

一级导航为 **调香室 / 探索 / 今日 / 我的**。页面之间共享草稿和收藏状态；返回时恢复原位置，不能因换页丢失配方。

### 3.1 调香室：默认入口

首屏直接看到一只空试配瓶、三个待选 base 位置和一句引导：“从三款喜欢的香气，开始今天的创作。”不预选用户偏好，也不先弹完整教学问卷。

页面按操作顺序包含：

1. **材料架**：当前商家/套件名称、已稀释状态、base 卡片与来源入口。点击卡片查看资料；“加入配方”为独立动作。
2. **配方纸**：选中材料、百分比输入、滑杆、合计与计划加入量；可移除材料、保存草稿。
3. **试配桌**：当前试配总量、玻璃瓶、各材料已模拟加入量、按住注入与一步加入入口。
4. **创作札记**：来自公开描述的气味侧面、配比变化的文字解释、用户自己的创作想法。
5. **完成区**：全部计划量加入后出现“命名并封瓶”；保存成功后进入作品详情。

材料不足或不支持混配时，资料仍可查看；“开始试配”旁说明缺少什么。没有来源支持的材料，不靠一个漂亮瓶子掩盖其不可计算状态。

### 3.2 探索：真实香水陈列

以真实商品照片、明确名称和版本组成陈列网格；提供搜索、品牌与香气标签筛选。图像区域固定比例，长名称正常换行。只计入已核验的真实条目；缺图或版本未核实的条目进入待完善状态，不用生成瓶图补齐。

产品卡的主要动作是“查看资料”；收藏使用独立按钮。图鉴商品只有进入有明确混配依据的 base 目录，才出现“加入配方”，不能把任意商品都当成可混材料。

空结果显示：“暂未收录符合条件的香水。”提供清除筛选，不编造替代产品。图片加载失败显示文字说明与重试入口，保留产品名称与资料链接，不呈现为真实商品图片已正常加载。

### 3.3 详情：一本打开的资料册

上部放真实产品图、品牌、完整版本、主要标签及“拥有 / 试过 / 想试”。下部依次是：品牌公开描述、官方香调、个人记录、相关风格、资料来源。来源和核验时间可展开查看。

“认识这些气味”展开代表原料与分子资料。小标题明确写“相关原料知识”，并使用“可产生类似木质侧面的原料”等表述；没有成分证据时，不画出该商业香水的分子配方。品牌资料、编辑解读、研究资料与个人感受分别标记。

桌面可采用图像与资料双栏；手机按同样的阅读顺序排列。页签和折叠面板可点击、可键盘操作，不做必须拖动或模拟翻页才能读到的内容。

### 3.4 今日与日记：轻量的日常入口

今日显示日期、手动场景与天气、已有实体香水的少量建议，以及“记一笔”。天气未接入服务时显示“手动选择”，不呈现虚构实时温度。

空香水柜的引导为“先放入你正在使用的香水”；没有推荐依据时提供手动选择，不伪装成系统已了解用户。记录分“今天用了香水”和“今天不用香水”，后者不要求选择产品。

日记最短路径为选择实体香水、确认时间、保存；评分和文字可后补。本人感受与同行者评价分开记录。纯虚拟作品只支持“记下创作想法”，不能直接进入穿香日记或今日用香推荐。

### 3.5 我的：作品架与香水柜

作品架展示用户命名、创建日期、版本和“虚拟作品”身份；实体香水柜单独展示拥有/试过/想试状态。两类内容不能仅靠颜色区别。

打开作品可查看完整配比、来源快照、计划量与创作札记；“继续调整”复制成新草稿，保留旧版本。提供 JSON 备份恢复入口，并清楚说明“保存在当前浏览器，尚未跨设备同步”。不将本地收藏称为上传、云端保存或发布。

## 4. 核心交互：从选择到封瓶

### 4.1 选材料、定比例

- 默认显示三个空位置；目录允许时提供“再加一款”。实际允许数量从商家规则读取，不能写死为任意目录均可四款。
- 第一款加入后为 100%，新增项为 0%；用户自行调整，不静默改写其他输入。零比例项保留在编辑器，但不计为本次实际使用的 base。
- 百分比支持 0–100%、一位小数；数字输入与滑杆并列。合计不足或超出 100% 时就近显示“还差 10% / 超出 5%”，可以存草稿，不能开始有效试配。
- “按当前比例调整至 100%”是用户主动操作，先显示新值再应用。全零不可归一化；所有有效比例都以稳定数值核对，不靠滑杆像素估算。
- 开始前校验商家支持的实际非零材料数量、来源体系、有效数值和合计 100%。材料数量不符时具体提示，例如“此套件支持 2–3 款，请调整所选材料”。

### 4.2 试配量与计量含义

默认 **10 mL 虚拟试配**，可切换 30 / 50 / 100 mL；这些选项表示本次数字试配的**名义投料总量**。材料为已稀释 EDP base，不出现默认 20% 浓度选项，不自动补加酒精。

示例：10 mL、比例 40/35/25 → 计划加入 4.00/3.50/2.50 mL。这里表示各 base 加入前量取体积的计划合计，不宣称真实混合后体积精确相加。主界面用“试配量 10 mL”；计量说明写“按各 base 的投料量合计计算”。动画液面是该计划完成度，不能作为物性模拟。

原型只显示当前商家允许的材料组合。未公开实体容量限制的商家，30/50/100 mL 选项仍明确属于虚拟试配，不宣称就是该商家可售套件或批准的实体方案。

### 4.3 按住注入、松开暂停

进入试配后，选中一款待加入的 base；按钮写明对象和余量，例如“按住加入玫瑰木质 · 剩余 3.50 mL”。旁边始终提供“本款一步加完”，一次点击即可补足该款计划量，支持键盘和辅助技术。

按住时，当前材料的瓶口高光、短液流和主瓶液面同步变化；配方纸同时显示“已加入 / 计划加入”。液色仅作统一的视觉示意，不按香调混出所谓真实颜色，也不把深浅当成浓度或扩散强弱。

注入规则：

1. 只有一款材料可以处于注入状态；只接受一次有效的主指针操作，多指触摸不叠加流速。
2. 按下后立即给出按压反馈，持续按住才启动注入；短按不会偷偷添加一大段量。持续确认时间以原型交互测试调整，不作为用户需要掌握的操作技巧。
3. 松开、指针离开有效区域、操作取消、焦点离开、切换页面或应用进入后台时立即暂停；保留已模拟加入量，恢复页面不自动继续。
4. 加入量由数值状态决定，始终限制在该材料目标量以内；到达目标时精确停止，按钮变为“本款已加入”。动画结束回调不承担计量正确性的责任。
5. 动画进度仅是操作节奏，不代表真实滴速或真实制备时间；不同试配容量无需让用户长按几十秒。一步加完得到同一数值结果，不能减少功能或失去作品资格。
6. 前一款完成后显示下一款可选材料，但不自动开启下一次注入。

每次从开始到暂停/完成视为一次可撤销操作；一步加完也记为一次操作。“撤销上次加入”恢复该次操作开始前的各项数量。注入进行中先停止，再执行撤销；不能出现仍在注入而同时回退计量的情况。

注入后若要改变材料、比例或试配量，入口明确为“修改配方并重新试配”。提示现有注入进度将归零，再由用户选择继续或返回；不能修改目标后沿用已经倒入的旧数量。封瓶前的草稿可在刷新后恢复，恢复状态始终暂停。

### 4.4 命名、封瓶、本地收藏

全部正比例材料均已达到目标量后，才可进入命名。标签纸提供名称输入和可选的一句创作札记；示例提示是“给这次创作起个名字”，不自动从姓名、位置或私人聊天生成内容。

点击“封瓶并收藏”后先完成本地写入，再给出盖上瓶盖、贴好标签的短反馈。成功文案：“已收藏这次创作。”副文案：“虚拟作品 · 保存在当前浏览器”。动画可跳过，不影响保存与后续操作。

保存中阻止重复提交；保存失败保留名称、配方和已加入量，显示“暂时没有保存成功，请重试或导出”。不能只播放封瓶动画就显示收藏成功。

## 5. 状态与操作约束

| 状态 | 可以做什么 | 进入下一状态的条件 |
|---|---|---|
| 选择与编辑 | 查看 base、调整比例、选择量、存草稿 | 材料与规则有效，合计 100% |
| 待试配 | 核对配方、选当前材料、开始加入 | 有可加入的目标余量 |
| 注入中 | 按住加入；松开/取消即暂停 | 达到当前目标或用户停止 |
| 已暂停 | 继续、一步加完、撤销、明确重新编辑 | 继续注入，或全部材料完成 |
| 待命名 | 填写名称、创作札记；可返回试配或撤销 | 全部计划量完成且名称有效 |
| 保存中 | 等待写入；保留当前内容 | 写入成功进入已收藏，失败回到待命名 |
| 已收藏 | 查看作品、备份、复制为新草稿 | 修改时创建新版本，不覆盖原作品 |

草稿数值非法、合计不为 100% 或资料不足时保留用户输入，并显示对应原因。已暂停与未开始均不自动注入；切换导航、弹层和浏览器后台不能改变这个约束。仅因有一张漂亮的成品瓶卡，不得把状态误标为已经收藏或实际制成。

## 6. 双端布局与可访问操作

| 屏幕 | 调香室布局 | 其他页面 |
|---|---|---|
| 360–767px | 单列、底部四项导航；“选材料 / 配比例 / 试配”按步骤切换，玻璃瓶与当前加入按钮同时可见 | 商品网格按可用宽度一至两列；资料册与版本比较纵向排列 |
| 768–1023px | 两栏：材料/配方面板与试配桌；屏幕高度不足时允许自然纵向滚动 | 资料与图片双栏，长正文控制行宽 |
| 1024px 以上 | 居中工作台，材料架—试配桌—配方纸三栏；顶部导航 | 陈列网格增加列数，不无限拉宽文字段落 |

页面必须支持 360、390、768、1024、1440px 的布局检查，以及手机横屏、浏览器放大和软键盘展开。小屏不通过缩小到无法点击的桌面全景保留三栏；固定导航和操作条为内容预留空间，并避开系统安全区域。

- 主要触控目标至少 44×44 CSS px，相邻操作至少有 8px 间隔。输入、移除、收藏均不依赖悬停或精确点中瓶口。
- 全程可通过点击和键盘完成。滑杆有数字输入替代；长按有一步加入替代；瓶子无需拖拽至其他瓶子上。
- 焦点顺序与页面步骤一致；弹层打开时聚焦标题或首项，关闭后回到发起控件。清晰显示焦点，不能被底栏挡住。
- 读屏获得材料名称、目标量、当前量及动作名称。暂停和完成时播报完整状态；不逐帧播报液面，也不因更新数字抢走焦点。
- 正文对比度至少 4.5:1，控件边界和有意义图标至少 3:1；纹理、透明叠层和真实图片背景上的状态需单独核对。
- 减少动态效果时关闭液流、晃动和大位移，保留数值进度及即时状态；一步加入照常使用。默认不自动播放声音，不以声音或振动作为唯一反馈。
- 动画只表达选中、加入、暂停、封瓶四类关系；列表不持续漂浮，不锁定滚动。反馈优先，不能等待漂亮动画才执行用户的暂停或返回。

证据标签固定为“品牌/商家资料”“研究资料”“编辑解读”“个人记录”。“已核验”仅用于核验过的具体字段，不为整个产品的配方、质量或兼容性背书。不使用“AI 闻到了”“精准复刻”“相似度 93%”“安全浓度已认证”等超出能力的文案。

## 8. 原型到正式产品的适配与验证

原型优先演示单个有依据的即用 EDP 体系，验证选择、配比、注入、撤销、封瓶和恢复。商家数量、可混目录及真实图片的实际覆盖应单独报告，不能因流程完整而声称已建成数十款材料库。

后续接入真实供应商时，继承 docs03 的两条路线：即用基础香水直接混配；浓缩香精按有依据的负载、单位和载体方案稀释。各目录保存商家与材料版本、允许组合数量、物料形态、规格、计量口径和步骤来源；未知数据进入记录模式。跨目录编号不通用，g 与 mL 不默认互换，EDP 不自动等于 20%。本轮注入动画不承担化学、挥发或适用性计算。

正式实体制备清单与本轮虚拟投料计划应有明确名称差异。只有材料及方案足够时才生成前者；实体调制完成由用户另建实际记录，不能把“封瓶收藏”自动视为已制成。

待执行的关键验收：

1. 10 mL、40/35/25 的计划量为 4.00/3.50/2.50 mL；长按与一步加入得到同一结果，均不超量。
2. 松开、移出、取消、切后台、换页立即暂停；回来不自行续倒；连续点击与多指输入不重复加入。
3. 撤销恢复上一段加入前的准确数值；改变配方或容量不能沿用旧注入量。
4. 非 100% 的合法配比可保存草稿，但不能进入有效试配；刷新恢复草稿后保持暂停。
5. 全程只用键盘或一步加入按钮，可以完成选择、试配、命名和收藏；减少动态效果不影响功能。
6. 本地写入失败时不出现收藏成功，配方和名称仍可导出；重复提交不产生重复作品。
7. 封瓶后的虚拟作品不进入今日实体用香候选；真实图鉴图片、材料来源、分子知识与编辑联想均有正确标签。
8. 手机、横屏、桌面和放大后的布局可读可操作；真实对比度、焦点、网络图片失败与存储失败均需实际检查。

以上是验收要求，尚不是测试通过记录。软件计量与交互通过，也不证明混合描述已接近真实嗅觉。
