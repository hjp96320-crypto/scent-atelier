# 聚类视图与相近探索修正

2026-11-09，项目：气味手记。依据用户三张实际页面截图，修正 [[27-香型板块热力图与直接拖动]] 的设计误判与状态恢复问题。

## 问题与修正

原版的八块来自档案首个香型标签，随后通过圆形排布、径向压缩和横纵拉伸形成显示岛屿，并不是聚类发现的形状。这层排版现已移除，同时移除 D3 hierarchy 依赖。全图采用原发布坐标，不重新训练，也不因筛选、选择或高亮改变点位。

33 个已验证的香调核心群组共有 8,501 条档案，采用实际香调名称及数量标注；其余 17,834 条不强行归组，以浅灰点保留。标签按可见范围与碰撞避让显示，放大可查看更多，全部群组仍可从选择器进入。筛选后的标签定位采用当前成员中的中心附近实际点，避免标签落在已被筛走的位置。真实群组在二维投影上可以相交，不承诺彼此隔开的规则岛屿。

密度改为按群组、等权真实点计算的连续高斯渐变，去掉原先六档填色产生的硬边和色块。浅深仅表达该群组图上的相对疏密，不能跨群组比较数量，也不是气味强度。少于 20 条不生成密度层。全图仍采用文档 24 所述香调／香型联合二维投影；群组则来自香调特征，两者并非同一计算，不能把二维距离当作实测气味距离。

“从这瓶出发”此前把 `atlasScope.ids` 当作结果过滤器，只留下起点及至多 48 个邻居，还切换布局、重新适配相机；移除标签时又没有恢复原视角。现在明确区分群组筛选和相近高亮：群组筛选仍改变结果，相近高亮只覆盖到完整当前结果上，不缩减背景、不改坐标、不自动放大。进入时保存相机，移除标签、再次点击取消或关闭所选香水时恢复该相机；显式改变筛选或重置时适配新结果。

按钮更名为“在星图中高亮相近香气／取消相近高亮”，计数同时显示背景总数和实际高亮数。手机点击高亮后收起详情并回到图形区域，避免面板挡住结果。普通相近推荐列表继续显示共同与不同线索，原有品牌、地区、香型筛选及地图保留。

## 底部标签联动（2026-11-09 后续反馈）

用户认为当前图已明显改善，但底部“花香／木质”等静态大类标签没有实际作用，也与图内的香调群组不对应。现将默认星图底部替换为“图中香调群组”：直接取当前可见图内标签的同一 ID、名称和筛选后数量；拖动、缩放时同步更新。点击图内标签或底部同名按钮，都定位并描边突出该组成员，两处同步显示选中状态；背景档案保留。再次点击或“返回全图”取消群组突出。按洲着色模式继续保留其对应的洲颜色说明。

验证：桌面图内与底部的 ID、名称、数量逐项一致；薰衣草／迷迭香 1,277 条、晚香玉／依兰 501 条均可选择，键盘 Enter 可操作。法国筛选后 8,347 条背景保留，两处群组数量同步为 348、286、275、231、58 等当前值。375 CSS 像素视口无横向溢出，按钮约 44px 高；点选与返回正常。原有相近高亮保留 26,335 条及相机还原回归通过；11 项相关 Node 检查通过，测试页无控制台错误。未重新训练聚类或改变发布数据，也未修改个人记录。
