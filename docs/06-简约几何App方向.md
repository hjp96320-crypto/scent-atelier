# 简约几何 App 方向

2026-11-08。用户认为艺术画册和手绘日记两方案过于花哨、不像 App，明确要求简约，尝试几何风。两套插画方案因此不再作为推荐基线。

新图位于 design-preview/geometric-app-concept.png，仍为视觉提案，尚未替换现有 H5。

- 白与冷浅灰底色、深灰正文，单一靛蓝强调色；统一无衬线文字、8px控件圆角、细线图标。
- 页面优先显示任务、进度、工作区、参数和主操作；取消营销大标题、植物、纸本纹理与贴纸。
- 桌面为瓶身预览与设置面板；手机为预览、参数、保存与底部导航。
- 配比→注入→瓶身三个阶段保留；当前图展示成品瓶身设置状态，不能当作已实现的注入状态截图。
- 保留方/圆/扁圆瓶、金/银喷头、金/银/无外盖、命名和保存；喷头与独立外盖清晰区分。
- 情绪反馈集中在注入、液面上升、暂停和作品完成，界面本身保持克制。2026-11-08 用户明确要求移除“试喷”，不再以喷雾动画充当气味体验。
