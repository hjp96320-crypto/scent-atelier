# 插画方向对比与喷雾瓶定制

日期：2026-11-08。状态：两张视觉概念供用户评估，尚未选定或接入 H5。

用户最新明确要求：成品瓶应为喷雾结构；支持主流瓶形的通用轮廓选择；喷头及外盖提供金、银配色；不满意现有风格雷同，希望尝试插画。随后指定分别评估“艺术画册”和“轻松手绘日记”两种方向。

## 两个方案

| 维度 | A 艺术画册 | B 手绘日记 |
|---|---|---|
| 视觉 | 奶油纸、钴蓝宋体、植物水彩、大面积留白 | 奶油黄、蓝色笔触、珊瑚与草绿、展开的手记 |
| 主体验 | 收藏一件私人香气作品 | 亲手完成一页气味日记 |
| 交互表达 | 细线选框、平静试喷、标签收录 | 勾选贴纸、手绘引导、贴标与试喷反馈 |
| 适合页面 | 图鉴、资料页、作品收藏 | 调香、自定义瓶、每日记录 |
| 风险 | 大标题和花卉可能抢走瓶子的注意力，容易偏展示 | 全页面纸笔装饰容易拥挤，需要收敛长文与表单区域 |
| 实现重点 | 插画层与可操作瓶体分层，保证文字为真实 DOM | 保留笔触特征，但命中区域、对齐、焦点使用规范控件 |

建议以 B 作为待选主方向，更符合用户提出的参与感与情绪价值；图鉴页降低插画密度即可，不需要混成另一套视觉。以上为设计判断，非用户最终决定。

## 喷雾瓶结构和选项

- 方瓶、圆瓶、扁圆瓶：以常见几何轮廓为起点，不复制品牌 logo 或声称可一比一复刻商品。
- 喷头：金色 / 银色，按钮、喷孔、泵环和瓶内导液管可辨认。
- 外盖：金色 / 银色 / 无外盖，与喷头颜色独立设置；试喷前移开外盖。
- 调配阶段展示开口注入；完成后安装喷头，之后可加外盖。不会把液体倒进已装好的喷嘴。
- 试喷是视觉动效，不代表用户通过屏幕闻到气味；正式实现需减少动态效果替代。
- 瓶型和金属配色只改变虚拟包装，不改变配比、用量或气味描述。选项应跟随作品保存与恢复。

两张图展示的是完成后的定制状态；原有注入、配比编辑、撤销和命名流程在实际改版时仍须保留。
