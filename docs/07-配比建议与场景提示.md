# 配比建议与场景提示

2026-11-08。状态：已更新设计要求；尚未接入现有 H5。用户要求提供香型搭配、配比与场景 tips，并移除没有判断价值的试喷动画。

## 1. 界面位置

配比编辑区下方显示一块紧凑建议区域，不另开弹窗、不遮挡输入；桌面位于参数面板，手机位于配比行之后。默认只展开最相关的一条，更多思路可展开。瓶身设置阶段不重复堆放调香知识。

每条只回答四个问题：为什么尝试这个组合、怎样开始配比、适合追求什么场景印象、如何根据实闻调整。标题用“搭配建议”，不叫“AI气味预测”。

## 2. 示例候选

下表比例是本产品提出的虚拟试配起点，不是商家官方配方，也未经实闻验证。例子对应当前目录已有的 Galimard 基底，按加入前的体积占比计算，总和100%；不把它泛化到浓缩香料、任意品牌或不同供应商。

| 想尝试的方向 | 候选组合与比例 | 场景印象：编辑建议 | 根据实闻再调整 |
|---|---|---|---|
| 清新、有一点木质支撑 | 佛手柑45 / 绿茶35 / 木质与零陵香豆20 | 通勤、白天外出，适合想要清新印象时作为候选 | 如果木质掩盖了茶感，比较一个降低木质比例的新版本，不断言当前就会过重 |
| 花香与柔和底色 | 牡丹50 / 麝香和弦30 / 绿茶20 | 日常见面、下午茶，适合想要柔和花香时作为候选 | 如果花香太突出，可减少其比例并比较茶感；麝香不自动等于轻柔或低扩散 |
| 温暖木质与明亮对比 | 木质与零陵香豆50 / 麝香和弦30 / 佛手柑20 | 微凉天气、晚间活动，适合想要温暖木质印象时作为候选 | 如果整体太厚，可比较增加柑橘、相应减少木质的版本；不承诺因此更安全、留香更短或扩散更弱 |

搭配方向的通用依据：EPC 的调香师介绍清新与深沉、花香与木质、绿意与美食调的对比搭配，并强调从少量组合、记录比例和实闻复评开始。来源：https://experimentalperfumeclub.com/blogs/journal/how-to-blend-a-fragrance 。该来源支持搭配思路，不支持上表具体 Galimard 用量或场景结论。

## 3. 随上下文变化的规则

- 选择基底后：仅匹配已选材料身份与有来源的气味标签，解释哪些方向值得尝试。不靠名称猜浓度、分子组成或实测强度。
- 改比例后：区分投料占比与嗅觉存在感；不把最大百分比直接叫气味主角。对小幅变化不声称可预测闻起来的精确差异。
- 选择办公室等场景后：说明同空间人的感受及实际用量也重要，不将“木质/麝香”自动判定为贴肤、不扰人。
- 有用户实闻反馈时：从“太甜、太突出、太淡、喜欢茶感”等明确反馈生成一个可比较的调整方向；记录它是用户反馈而非模型检测。
- 无可核验材料或浓度规格时：只给搭配思路，不给确定实体稀释配方。

## 4. 交互与配比保护

“试试这个比例”先展示新旧配比及用量差异。尚未注入时，用户点击应用即可，仍校验100%；已有注入进度时创建新版本，不往当前瓶中反向扣除材料。原草稿保持可返回。

建议以一个变量的对比开始，例如40/35/25与45/35/20；实际制备按适用供应商的小样流程。不要把3–4款的产品交互规模变成“材料越多越好”。

## 5. 页面示例文案

**搭配建议 · 清新木质**

可以尝试让柑橘与茶感作为清新方向，少量木质提供对比。

试配起点：佛手柑45% · 绿茶35% · 木质与零陵香豆20%。

场景参考：白天外出、通勤；具体接受度仍取决于实闻与使用量。

说明：编辑建议，非官方配方。体积占比不等于气味强度。

操作：查看配比差异 / 更多思路。

## 6. 移除项

移除试喷按钮、喷雾粒子动画、以试喷表现香气差异的说法。喷头、导液管、独立外盖与金银自定义仍保留，它们属于包装设计。

验收：建议可说明依据；百分比合计100；未知不编造；场景为可调整参考；没有试喷入口；应用建议不能破坏已注入记录。
