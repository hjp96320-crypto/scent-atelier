# 今日流程与 iOS 风格优化

2026-11-08。使用 ui-ux-pro-max 指南；修正今日选香灵感位于整月日历下方的问题，并调整四页共享的导航、控件、卡片和弹窗样式。

## 使用顺序

1. 打开今日即可选择天气、场景。天气是手动输入，不暗示已接入实时天气。
2. 看带真实图片、明确版本和气味印象的香水卡。没有香柜时从 100 个精细档案中找探索灵感；有香柜时只从已拥有香水中选。
3. 选择“记录这瓶”，表单预填该香水、当天日期、当前天气及场景。顶部“记录用香”是独立快捷入口；日历补记仍使用所选日期。
4. 在下面的用香日历回看记录。保存后月份统计和当天条目立即更新。

匹配只按香型和编辑规则，不预测实测气味强度、持香或扩散。没有对应香型时明确提示，不制造虚假匹配理由；切换条件不修改香柜或历史记录。

## 设计依据

[Apple Liquid Glass 设计说明](https://developer.apple.com/videos/play/wwdc2025/284/)将导航和工具栏作为浮在内容上的功能层。本轮借鉴这一层次，用 CSS 半透明、背景模糊、轻边缘与阴影实现 H5 近似；不声称是原生折射材质。

保留深绿色品牌色。统一系统无衬线字体、胶囊主导航与按钮、圆角内容分组；手机底栏留出安全区。正文用实体底色，新增组件最小触控高度 44px，保留选中语义、可见焦点以及减少动画/透明度的 CSS 降级。页面遵循内容优先，不加入大范围装饰动画。

Skill 的首轮系统检索误匹配到 Newsletter / Swiss Modernism，未采用其营销结构、字体及配色；按契约缩窄到 Glassmorphism 风格检索，参考其导航分层与对比度要求，低透明内容卡建议未采用。

## 验证与限制

- 56 项 Node 自动检查全部通过；新增两个测试覆盖空香柜探索、条件影响结果、个人香柜优先、没有匹配时如实说明以及不修改输入数据。
- 浏览器在独立 4190 端口验证无香柜 → 看详情 → 加入香柜 → 记录这瓶 → 预填天气/场景 → 保存 → 日历计数更新，刷新后记录仍在。
- 检查桌面、375×812 手机及 812×375 横屏；页面无横向溢出，新增选择按钮和导航触控高度均不少于 44px。图鉴、调香比例页和香柜导航也已检查。
- 浏览器控制台未出现错误。主用 4187 端口的用户数据未操作；测试使用独立端口数据，未修改数据结构或配方算法。
- 减少动画/透明度为样式级支持，未做真实 iPhone 系统开关、最大 Dynamic Type 或读屏测试。当前为浅色主题，未实现深色模式。
