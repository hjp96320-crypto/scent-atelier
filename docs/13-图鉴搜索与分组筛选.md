# 图鉴搜索与分组筛选

日期：2026-11-08。延续现有简约几何界面，本轮仅调整图鉴搜索和筛选。

## 已实现

- 国家／地区：48 项按亚洲、欧洲、北美洲、南美洲、非洲、大洋洲分组。俄罗斯、土耳其单列为“跨洲（欧亚）”，每个地区只出现一次；各组内按中文排序。
- 品牌：1,263 个原始品牌标签完整保留。选择面板按原名首字母 A–Z 分组，数字开头归入 0–9；组内按原名排序，中文译名优先展示，同时显示原名和收录条数。
- 品牌查找：支持中文、品牌原名、忽略大小写及拉丁字母重音、兼容手机弯引号。桌面显示字母索引，窄屏使用首字母选择框。每批显示 60 项，可继续加载；空结果提供查找提示。
- 图鉴主搜索：多个关键词以空格分隔并同时匹配，如“迪奥 旷野”；兼容多余空格、重音字母与弯引号。
- 保留品牌、地区、香型、关键词的组合筛选。选择品牌后返回图鉴并更新结果；关闭面板保留原条件，Esc 返回筛选按钮，品牌列表支持上下方向键及 Home/End 定位。

## 验证

- `node prototype/catalog-filter-groups.test.mjs`：48 地区、1,263 品牌均完整且唯一地进入分组；排序、数字、重音、中英文、引号和空结果通过。
- `node prototype/catalog-presentation.test.mjs`：多关键词、重音、弯引号和既有中文展示回归通过。
- `node prototype/catalog-full.test.mjs`、`node --check prototype/app.js` 通过。
- 浏览器操作：品牌加载 60 → 120 项；中文“迪奥”、英文“chloe”、弯引号“L’Artisan”搜索；空结果提示；键盘选择与 Esc 返回；迪奥＋法国＋花香得到 106 条；主搜索“迪奥 旷野”得到 8 条。
- 默认桌面视口、375×667 手机视口及 812×375 横屏检查通过；手机首字母选择、加载更多可用，图鉴无横向溢出。横屏面板允许滚动访问全部控件。浏览器未捕获 error/warn；属于浏览器视口验证，未在实体手机上测试。
