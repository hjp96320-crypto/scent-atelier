# 第一批原型优化：个人记录与编辑草稿

2026-11-08。范围为本地 H5，不进行 App 封装。

## 已实现

- 日记编辑：香水、日期、感受、天气和场景；支持修改已移出香柜但仍存在于图鉴的历史用香记录。保存失败回退内存，保留表单。
- 日记和作品软删除：确认对象后移入最近删除；在“我的”恢复，刷新后仍保留。恢复同编号记录不静默覆盖。
- JSON 合并导入：20 MB 上限、格式/版本/编号/香水引用/日期/配方用量校验；数量预览、去重，冲突展示两份内容并要求逐项选择。写入前保留原数据快照，可在下次导入窗口下载。
- 选香和配比草稿：独立保存编辑步骤、选择、用量和比例，允许未合计 100% 的配比继续编辑；进入注入或选择继续原瓶时清除编辑草稿。

## 验证

- 37 项 Node 测试通过；新增 7 项覆盖文件校验、损坏用量、重复编号、冲突选择、幂等合并及编辑草稿。
- 独立 4188 端口：三款选香、比例改为 45% 后刷新恢复；非法日期备份拒绝；有效备份预览与合并；日记日期/天气/感受编辑并刷新；软删除、恢复与日历日期联动；冲突未选时阻止合并，选择保留本机后通过。控制台无 error。
- 正常使用的 4187 记录未用于修改、删除和导入测试。未模拟设备存储耗尽、真实手机文件选择和多标签同时写入。

## 明确边界与后续

本轮导入合并作品、香柜和日记有效记录，保留本机正在进行的调配。导出中包含的注入/编辑草稿目前不能通过导入替换本机草稿；最近删除需先恢复再导出。尚未实现覆盖全部恢复模式、作品重命名与备注。第二批操作体验与第三批内容完善继续待办，不能声称整轮规划全部完成。
