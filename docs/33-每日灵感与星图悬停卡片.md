# 每日灵感与星图悬停卡片

日期：2026-11-09

## 每日灵感

- 沿用天气、场景的香型评分；优先个人香柜，空香柜使用已核查热门款。
- 最高分及相差不超过 1 分的候选参与轮换；存在正分匹配时不纳入零分候选。
- 按设备本地日期选择，同一天、相同候选集合保持相同默认推荐。候选超过一款时，相邻日期轮换；只有一款匹配时继续展示该款，不为了变化而强行推荐不匹配香水。
- 新增“每日更新”日期和“换一瓶”。手动切换在本次页面会话内保留，刷新后恢复当日默认；天气或场景改变后重新匹配。
- 页面停留到本地午夜时更新；后台休眠后恢复可见时检查日期；离开今日页取消计时器。
- 天气和场景仍由用户选择，没有接入真实天气服务。

## 星图卡片

- 使用档案原有真实图片、中文优先名称、品牌、具体浓度版本、地区和最多三个已列香调。
- 靠近边缘时向图内避让；卡片不接管指针，保留圆点点击和地图拖动。
- 仅精细指针且支持悬停时出现；触屏继续通过点选与列表查看详情。
- 对插入 HTML 的目录字段统一转义，长文本限制宽度；切换地图后恢复地图提示样式。
- 使用 deck.gl 官方 getTooltip 的 html、className、style 接口：https://deck.gl/docs/api-reference/core/deck#gettooltip

## 验证

- 自动化测试覆盖日期稳定、每日轮换、手动轮换、香柜优先、空候选、单候选、月末年末午夜、HTML 转义和卡片四边定位。
- 浏览器验证“换一瓶”、天气切换、同日刷新保持默认，窄屏无横向溢出，操作按钮高度不低于 44px。
- 浏览器点位预览中真实图片加载成功，卡片完整位于图表边界内；点击密集点位仍展开候选列表，错误日志为空。
- 跨日行为通过注入测试日期验证，未改变系统时间或等待真实午夜。
