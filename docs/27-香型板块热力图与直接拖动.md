## 当前行为与口径

默认显示“香型板块”。按每条档案现有的首个香型标签确定唯一板块，自动从数据生成，当前为 8 类：花香 10,782，木质 7,049，琥珀 2,362，馥奇 2,331，柑橘 1,606，西普 1,133，皮革 1,070，果香 2；总和 26,335。15 类复合香型筛选保持原行为，因此某香型筛选结果可散落在不同板块中。首标签只是库中分类顺序，不宣称实测的主导香气。这里不是把原先 33 个稳定核心重新聚成 8 类。

板块之间采用 D3 circle packing 排版；每个板块内沿用发布坐标的方向关系，用径向 asinh 与线性项混合压缩远端离群点。板块视图按容器宽高适配，面积和间距均不作定量编码。切换“相似关系”可查看未经这些显示变换的原全局坐标；从某瓶出发时自动切至此视图。原始特征、相近推荐、33 个核心群组、26,335 个档案 ID 与版本不变。

密度用每条真实档案等权、固定数据空间核的高斯平滑网格计算，累加为 Float64，按板块当前筛选的峰值归一化，分六档色阶显示。六档是颜色层次，与板块数量无关。缩放只改变相机，不重算密度；不同板块的色深不能作数量比较，标签给出实际数量。少于 20 条不绘制热点，只显示真实圆点；果香 2 条没有虚构的热力面积。没有随机装饰点。

直接显示名称与数量，点名称放大；所有原始点仍可选择，重叠点打开真实候选列表。星图和地图均启用直接拖动、滚轮、双指缩放，取消“操作图形”门控。保留加减号、适配当前结果、方向键、0 键和完整结果列表。窄屏缩放按钮放到画布下方，避免遮住板块。

## 实现与依赖

- deck.gl 9.4.1：OrthographicView / MapView，ScatterplotLayer / BitmapLayer / GeoJsonLayer。本地按需加载，原 ECharts 运行时已移除。
- d3-hierarchy 3.1.2：只用于实际香型板块的非重叠排版。原生 H5，不迁移框架。
- 密度先在 CPU 计算，再作为纹理由 deck.gl 绘制，避免依赖移动 GPU 浮点纹理累加精度；不再使用尝试阶段的 GPU HeatmapLayer。
- Natural Earth 本地底图继续使用，不接在线底图服务。
- 来源与许可证：`prototype/vendor/README.md`。官方技术依据：[deck.gl 视图](https://deck.gl/docs/api-reference/core/orthographic-view)、[交互控制器](https://deck.gl/docs/api-reference/core/controller)、[D3 packing](https://d3js.org/d3-hierarchy/pack)。

## 功能和设计验收

继续按 ui-ux-pro-max 与 Impeccable 的可读性、触控、键盘、真实渲染标准复核。已修正：颜色单独编码、板块名称缺失、门控拖动、375 像素时标签重叠与缩放按钮遮挡。桌面板块铺满可用宽度；全局相似关系保留等比坐标。

- Node 全套 67 项通过。新增检查涵盖实际标签分组、全部身份保留、可重复位置、原坐标不变、板块不重叠、小样本处理、等权密度与更高样本量对应更深密度。删去已移除的网格圆点聚合测试。
- 修复浏览器实测发现的“独立 X/Y 拟合后拖动，再点放大会变为 NaN”：控制器返回 zoom 数组，现统一为控制用标量并保留两轴；回归测试通过，浏览器复验两轴增量均为 0.6。
- 实际鼠标拖动：星图 target 改变；地图 longitude/latitude 改变。地图拖动后继续放大有效。点板块放大、点图中圆点打开 24 条候选、尼罗河花园详情、49 条近邻范围、地区筛选法国 8,347、空结果和恢复 26,335 均验证。
