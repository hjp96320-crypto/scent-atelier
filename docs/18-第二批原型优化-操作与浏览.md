# 第二批原型优化：调配反馈与图鉴浏览

2026-11-08。按用户确认继续完善本地 H5，不进行 App 封装。

## 已实现

- 用量显示统一一位小数，包括配比页、投料进度、配方列表、作品详情与瓶子辅助描述。
- 新增每次加入 0.5 mL；不足 0.5 mL 时“补足剩余用量”，仍按目标准确完成。内部整数计量不改，保留旧配方和保存兼容性。比例滑块改为每格 0.5%，数值输入仍支持一位小数。
- 配比合计反馈补充约差/超出多少 mL。逐款注入区域显示当前材料、剩余量、整体进度和已完成数量；待保存/已保存状态继续明确区分。
- 图鉴当前条件标签可独立移除；品牌/地区/香型/搜索词/页码/滚动位置保存在当前标签会话，切页与刷新可恢复。桌面导航固定在顶部。
- 补充祖马龙、迪奧、香奈爾、YSL、TF、蓝香奈儿、狂野等搜索用词，支持大小写、重音和部分标点差异；不改变商品命名与版本资料。已明确的浓度版本在卡片中突出展示。

- 42 项 Node 测试通过，新增覆盖半毫升尾量补足、单小数显示、无效比例提示、筛选状态恢复及别名/标点搜索。
- 独立 4189 端口：搜索“祖马龙 英国梨小苍兰”返回 3 条；法国+木质筛选和分页、单条件清除、切到今日再返回恢复、刷新恢复。
- 实际点击固定导航后，返回到相同 354px 阅读位置；自动化 locator 点击导航会主动滚动后再点击，因此该场景改用截图坐标实际点击验证。
- 33.3/33.3/33.4 配比：第一款分次加入至3.0 mL，再补足；其他两款到量后总计10.0 mL，完成后命名保存，刷新可见。
- 375×812 手机注入按钮和进度检查，无横向溢出。截图 design-preview/round-two-mobile-dose.png。所有测试作品仅在4189，未修改4187已有作品或日记。

## 边界

用量为一位小数显示约数，逐项四舍五入后显示值相加可能与总量相差0.1 mL；底层计量和实际完成状态不以显示值判断。长按仍连续注入。未在实体手机测试，未增加云同步或嗅觉预测。
