# 品牌城市地图与国家缩放

2026-11-09，气味手记 H5。延续 [[29-地图地区选择与香水入口修复]]，按用户要求加入真实城市位置与国家自动缩放。

## 已实现

- 世界地图 → 国家分布 → 城市品牌 → 具体香水与版本。点击地图国家、地区列表或全局地区筛选，自动适配国家范围；城市再放大一级。650ms 过渡支持减少动态效果设置，拖动与缩放仍可使用。
- 国家内部显示浅色行政边界与城市标记；相同城市的品牌合并，数字表示当前筛选中的品牌数。标签围绕真实城市点上下左右避让，必要时隐藏重叠标签，侧栏始终提供完整城市入口。
- 世界／国家／城市路径及返回按钮保留层级。品牌列表使用现有真实香水图片；“浏览全部”沿用现有分页与完整档案弹窗，不改变用户香柜。
- 窗口宽度变化后适配当前国家或城市；手机点选国家回到地图，点选城市进入城市内容。未知城市的品牌保留在“暂未定位到城市”列表。

## 数据口径与覆盖

首批为 **42 个品牌、29 座城市、14 个国家／地区、4,077 条现有香水档案**。全库仍为 26,335 条、1,263 个品牌；另外 1,221 个品牌没有本轮核实的城市位置。这是城市数据覆盖范围，不是品牌分布的完整统计，不代表市场份额。

每品牌只选一座有明确来源的代表城市，并区分创立城市、总部／品牌所在地或工坊／工作室城市。品牌跨国集团母公司、生产地、创立地不混用。点位是城市代表点，不能作为门店或建筑导航地址。

品牌关联的官网／品牌集团资料及查询日期保存在 `research/catalog-visualization/brand-city-sources.json` 和运行时 `prototype/assets/atlas/brand-locations.json`；没有把来源链接添加到香水详情。坐标来自 [GeoNames 城市数据](https://download.geonames.org/export/dump/readme.txt)，以国家代码和城市精确名称匹配，并保存 GeoNames ID，遵循 CC BY 4.0 署名。

行政界线使用 [Natural Earth 1:10m admin-1](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_1_states_provinces_lines.geojson)，压缩属性并进行 0.015° 简化；是静态参考底图，不是实时行政调整记录。法国和美国初次进入适配主要本土及已核实城市，避免海外领地把相机拉回世界尺度；俄罗斯跨日期线按连续经度处理。没有引入在线地图密钥或外部瓦片依赖。

构建脚本：`research/catalog-visualization/build-brand-locations.py`、`build-map-boundaries.py`。运行依赖同目录已下载的上游数据副本。浏览器只加载精简结果，不读取原始 ZIP／GeoJSON。
