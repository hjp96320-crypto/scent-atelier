## Skills 审计与已完成修正

使用 ui-ux-pro-max 的图表、触摸替代操作指南及 Impeccable audit／craft-floor。静态 detector 结果 `phase1-detector.json` 为 `[]`，仅表示该检测器没有发现规则命中。

| 发现 | 影响 | 修正与复查 |
| --- | --- | --- |
| P1 手机筛选、统计挤占图形 | 选香时看不到足够图形 | 高级图形选项收起、隐藏重复统计，保留搜索和明确定位按钮；375px 实际检查 |

| P2 输入时自动弹出抽屉 | 打断搜索过程 | 仅明确定位、回车或点选时打开；实测搜索与定位 |

| P2 地图色阶缺少直观上限 | 颜色难以理解 | 色阶显示实际最大品牌／档案数和 0 |
