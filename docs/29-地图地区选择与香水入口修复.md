# 地图地区选择与香水入口修复

2026-11-09，项目：气味手记。

## 问题与修正

地区点击此前只更新筛选，地图控制器没有收到所选地区，侧栏仍重复展示地区列表。选择俄罗斯后显示 7 条，但无法继续进入香水。地图又只允许点击当前筛选结果包含的地区，导致选过一个国家后难以切换。

现在地图与侧栏共用地区选择入口：选择地区后显示品牌数、香水数、品牌名称和带真实图片的香水列表，点击香水直接打开完整档案。超过 8 款时提供“浏览全部”入口，使用现有分页结果列表。“返回地区列表”仅清除地区筛选。地图支持直接切换到全库已收录的其他国家；手机选择后将地区内容滚动到视口。

资源版本更新为 `20261109-map-region`。未修改图鉴数据、聚类坐标或用户个人记录。

## 验证

- 修复前在隔离源复现：俄罗斯地区被点击后，侧栏保持地区列表，香水入口为 0。
- 修复后俄罗斯显示 1 个品牌、7 款香水，图片均加载；Maroussia 可打开完整档案。
- 实际点击地图俄罗斯区域，成功从之前的日本筛选切换到俄罗斯。
- 法国显示 334 个品牌、8,347 款香水；“浏览全部”打开每页 24 条的结果列表，可继续打开可可小姐 EDP。
- 返回地区列表恢复 48 个地区；375 CSS 像素视口无横向溢出，打开详情再关闭后仍保留俄罗斯的 7 款结果。未进行物理手机触摸测试。
- 11 项图鉴模型、相近探索与密度测试通过；相关 JS 语法检查通过，测试页未出现控制台错误。
- 主入口 `http://127.0.0.1:4187/#explore` 已确认使用新流程。隔离测试源 4198 已关闭。
